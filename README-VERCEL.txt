CODEDARK STORE - VERCEL

Este pacote foi separado do workspace do Replit e preparado para publicação como um projeto Vite independente na Vercel.

CONFIGURAÇÃO AUTOMÁTICA:
- Framework: Vite
- Build Command: npm run build
- Output Directory: dist
- Base URL: /
- Rotas SPA: configuradas em vercel.json

PUBLICAÇÃO:
1. Extraia este ZIP.
2. Na Vercel, importe a pasta/projeto.
3. Não defina Root Directory para artifacts/codedark-store: este pacote já começa na raiz correta.
4. Faça o Deploy.

Não são necessárias as variáveis PORT ou BASE_PATH que eram exigidas pelo projeto original do Replit.
